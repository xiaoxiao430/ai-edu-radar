# 厚外AI教育项目精选平台

一个公开资料库和个人开发选择界面。每天以教育项目为主，补充适合改造成教学工具的通用项目；阅读图文评价后，可以勾选、排优先顺序并生成开发 Prompt。

网页入口：[厚外AI教育项目精选平台](https://xiaoxiao430.github.io/ai-edu-radar/#path)。网站代码和公开资料在本仓库；个人勾选、备注与优先级仅保存在使用者当前浏览器，可导出、恢复，不提交 GitHub。

## 内容与用法

- 按学段学科选：学段→学科→具体教学场景，也支持场景→学段→学科；每个功能可保存多个教学位置，分别生成目标、师生活动和验收。
- 项目大全：统一浏览全部历史精选项目与338项教学功能参考，支持按类型、场景、学段、学科、投入和建议次序筛选；相近功能保留原编号，条目数不代表独立产品数量。
- 今日精选：每期目标10项，查看真实来源、配图、教学改造建议与投入判断。
- 教育场景：62类场景，可按学段、学科与建议顺序查找。
- OurTeacher图文库：338项简体主目录、48项繁体补充、34条抖音代表资料，另附可公开访问的官方操作教程。2条测试记录不进入可选清单。数量表示目录条目，不表示互不重复的成熟功能。
- 我的开发清单：选择具体内容，调整为待排期、先做、后做或暂缓，补充备注后复制、下载开发 Prompt。

选择一个场景不会自动选择其全部工具。系统推荐和个人安排分别显示；勾选不自动运行开发或启用付费服务。

图片区分产品实图、演示站截图、官方教程封面和教学用法示意。缺少真实内部界面的条目标明待补，不把图标或示意图当作功能截图。功能与效果以具体核验记录为准，资料介绍不等于课堂效果已经验证。

## 本地检查与发布

仓库使用原生 HTML、CSS、JavaScript 和 JSON，无需安装依赖。使用 Node.js 22 或更新版本：

```bash
node scripts/validate.mjs
node scripts/build-snapshot.mjs
python3 -m http.server 8000 --bind 127.0.0.1
```

构建生成单文件离线版本 `downloads/ai-edu-radar.html` 和发布目录 `dist/`。离线快照只包含最新一期精选及完整OurTeacher参考库，并内联本地图片、数据、脚本和样式，避免单文件随每日历史不断增大；页面会注明这一范围。在线网站继续保留全部历史精选。访问外部来源仍需联网。仅允许名单内的网站文件进入发布产物。

当前使用GitHub内置的Pages构建发布：源文件保存在main，检查和构建通过后，将dist允许名单内容发布到gh-pages分支，由GitHub的“pages build and deployment” Actions工作流上线。当前GitHub凭据不含自定义workflow写权限，因此不要求重新授权；自定义工作流模板仅保留在ops中，不自动启用。

源文件提交并推送main后执行：

```bash
node scripts/publish-pages.mjs
```

脚本会再次检查、生成快照，通过现有gh授权的GitHub API正常快进发布gh-pages，不强制覆盖分支历史。然后核对GitHub Pages构建成功与网站内容。若上传main的Git连接超时，可执行`node scripts/push-via-api.mjs`；它同样使用现有gh授权，核对文件和提交摘要，不输出或另存令牌。

## 每日更新

每日检索通过已授权的 Codex 定时任务执行，默认北京时间08:30；GitHub Actions 负责构建与发布，不负责联网选题。该任务需要执行设备和 Codex 可运行。

操作流程与数据约定见 [DAILY_UPDATE.md](DAILY_UPDATE.md)。未能完成检索或检查时保留最后成功版本，网站显示最后成功更新时间。不要通过重复旧项目或虚构来源补足数量。

页面融入学校认可的厚外校徽和厚德娃形象，以“做懂的教育”和六好育人为背景；校徽、厚德娃仅用于获授权的本校平台展示，不属于可自由再分发的通用开源素材。亮色界面采用深色文字和清楚的图文、对照表。

每项功能参考有单独的教学流程示意图；能够取得公开操作教程的条目优先展示真实画面，并注明出处及时间点。抖音公开访问有范围限制，本库34条代表资料不等同于账号全部作品，未将无法读取的页面写成已完整抓取。

所有界面文字使用微软雅黑。项目不附带微软字体文件；客户端字体可用性由浏览器设备决定。网站不收集真实师生信息，不需要后台、登录、管理密码或模型 API 密钥。


## 按教学位置规划

`data/teaching-map.json`保存学段、学科／工作领域和场景的具体适配关系，当前4051条，覆盖338工具、10精选项目与60类明确场景。关系数不表示独立产品或成熟课程数。幼儿园采用发展领域；管理、学情和教研独立列出；C57与C62待核，不强行配入学段。小学采用适龄场景名称，不直接套用初高中学科名。

同一工具可以加入“小学·英语·词汇练习”和“高中·英语·词汇练习”等多个教学位置，分别保留目标、师生活动、输出与验收。取消一处不会删除其他位置。原先未指定位置的选择仍保留，可从开发清单补充。导出、导入和离线版本均支持这些位置。选择快照不重复保存大图片，避免离线勾选耗尽浏览器空间。

## 抖音资料的纳入与补齐

`data/douyin-catalog.json`为逐作品整理记录：已发现82条（原34条＋新增48条，其中44条新增官方作品、4条其他作者被排除）；32条实用内容进入默认列表，25条同功能作品合并留源，25条宣传、导流、仅外观或来源不符记录不进入默认列表。原始34条仍单独留档，338官网工具与22官网教程不冒充抖音作品。

账号完整列表和部分封面无法正常读取，当前`complete:false`。用户截图中的2394为截图时作品数，不是本次枚举到的实时总数。只有取得完整作品目录、逐条有纳入／合并／排除记录并对齐统计后，才能标为全量完成。网站清楚显示当前范围和补齐方式。
