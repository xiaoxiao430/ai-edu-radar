# AI教育项目精选库与开发选择台

一个公开资料库和个人开发选择界面。每天以教育项目为主，补充适合改造成教学工具的通用项目；阅读图文评价后，可以勾选、排优先顺序并生成开发 Prompt。

网页入口：[AI教育项目精选库](https://xiaoxiao430.github.io/ai-edu-radar/)。网站代码和公开资料在本仓库；个人勾选、备注与优先级仅保存在使用者当前浏览器，可导出、恢复，不提交 GitHub。

## 内容与用法

- 今日精选：每期目标10项，查看真实来源、配图、教学改造建议与投入判断。
- 教育场景：62类场景，可按学段、学科与建议顺序查找。
- OurTeacher参考库：338项简体主目录、48项繁体补充、34条抖音代表资料。2条测试记录不进入可选清单。数量表示目录条目，不表示互不重复的成熟功能。
- 我的开发清单：选择具体内容，调整为待排期、先做、后做或暂缓，补充备注后复制、下载开发 Prompt。

选择一个场景不会自动选择其全部工具。系统推荐和个人安排分别显示；勾选不自动运行开发或启用付费服务。

图片区分产品实图、演示站截图、官方教程封面和教学用法示意。缺少真实内部界面的条目标明待补，不把图标或示意图当作功能截图。功能与效果以具体核验记录为准，资料介绍不等于课堂效果已经验证。

## 本地检查与发布

仓库使用原生 HTML、CSS、JavaScript 和 JSON，无需安装依赖。使用 Node.js 22 或更新版本：

```bash
node scripts/validate.mjs
node scripts/build-snapshot.mjs
python3 -m http.server 8000
```

构建生成单文件离线版本 `downloads/ai-edu-radar.html` 和发布目录 `dist/`。离线快照只包含最新一期精选及完整OurTeacher参考库，并内联本地图片、数据、脚本和样式，避免单文件随每日历史不断增大；页面会注明这一范围。在线网站继续保留全部历史精选。访问外部来源仍需联网。仅允许名单内的网站文件进入发布产物。

当前使用GitHub内置的Pages构建发布：源文件保存在main，检查和构建通过后，将dist允许名单内容发布到gh-pages分支，由GitHub的“pages build and deployment” Actions工作流上线。当前GitHub凭据不含自定义workflow写权限，因此不要求重新授权；自定义工作流模板仅保留在ops中，不自动启用。

源文件提交并推送main后执行：

```bash
node scripts/publish-pages.mjs
```

脚本会再次检查、生成快照，并以正常快进提交发布gh-pages，不强制覆盖分支历史。然后核对GitHub Pages构建成功与网站内容。

## 每日更新

每日检索通过已授权的 Codex 定时任务执行，默认北京时间08:30；GitHub Actions 负责构建与发布，不负责联网选题。该任务需要执行设备和 Codex 可运行。

操作流程与数据约定见 [DAILY_UPDATE.md](DAILY_UPDATE.md)。未能完成检索或检查时保留最后成功版本，网站显示最后成功更新时间。不要通过重复旧项目或虚构来源补足数量。

所有界面文字使用微软雅黑。项目不附带微软字体文件；客户端字体可用性由浏览器设备决定。网站不收集真实师生信息，不需要后台、登录、管理密码或模型 API 密钥。
